# Newsletter - Thực hành phối màu với Adobe Color

## Mục tiêu
Hoàn thành 2 phiên bản newsletter với 2 bộ màu khác nhau, áp dụng bằng biến CSS để dễ thay đổi màu.

## Phiên bản 1
- Primary: `#4F46E5`
- Secondary: `#3730A3`
- Accent: `#7C3AED`
- Text: `#1F2937`
- Light background: `#EEF2FF`
- Dark primary (hover): `#312E81`

## Phiên bản 2
- Primary: `#0F766E`
- Secondary: `#115E59`
- Accent: `#0891B2`
- Text: `#172554`
- Light background: `#ECFEFF`
- Dark primary (hover): `#134E4A`

## Cấu trúc
- `version1/index.html`: Newsletter phiên bản 1.
- `version2/index.html`: Newsletter phiên bản 2.

Mở từng file `index.html` bằng trình duyệt để xem kết quả.
